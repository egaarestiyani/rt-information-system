# Sistem Informasi RT Berbasis Web

## Deskripsi
Sistem Informasi RT merupakan aplikasi berbasis web yang dikembangkan untuk mendukung digitalisasi administrasi lingkungan. Aplikasi ini membantu pengurus RT dalam mengelola data warga, pengaduan, dan penyampaian informasi secara lebih efektif dan efisien.

## Fitur Utama
- Login & Autentikasi
- Dashboard
- Manajemen Data Warga
- Manajemen Pengurus RT
- Manajemen Pengaduan
- Manajemen Informasi
- Export PDF, Word, dan Excel
- CRUD Data

## Teknologi
- Laravel
- PHP
- HTML
- CSS
- JavaScript
- MongoDB
